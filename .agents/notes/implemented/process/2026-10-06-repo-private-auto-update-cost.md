# Agent Note: 仓库转为 private：以应用内自动更新为代价

Status: implemented

## Problem

原 `docs/DECISIONS.md` D14（从 DECISIONS.md 迁移）。

业主指令把仓库转为 **private**。这个动作有一个不明显的后果：**应用内自动更新彻底失效。**

事实链（全部实测，不是推断）：

- 客户端的 updater 端点是
  `https://github.com/iuuuuuuuu/ai-gateway/releases/latest/download/latest.json`
  （`src-tauri/tauri.conf.json` 的 `plugins.updater.endpoints` 第一项）
- 该仓库 2026-10-06 转为 private 后，**匿名**访问
  `releases/latest/download/latest.json` / `api.github.com/.../releases` / 仓库页
  **全部 404**
- `tauri-plugin-updater` 是**匿名 HTTP 拉取、不带任何凭据** ⇒
  **加 `Authorization` 头也救不了**，这不是配置问题
- 对照实测（同一台机器上的 A/B）：另一个私有仓库的同一路径匿名 = **404**，
  而同期的本仓库（当时 public）= **302** ⇒ 不是猜测

**影响面包括业主自己桌面那一版** —— 端点写死在客户端里，
所以「用户点检查更新」这条路对**所有已安装的客户端**都断了。

## Decision

仓库按业主指令转为 **private**，并**接受自动更新失效**这个代价。

这是一个**产品口径**决定，不是技术判断 —— 技术侧能做的只是把代价说清楚。

### 诚实边界：转 private 对安全没有实质收益

全量扫描 **850 个 tracked 文件**，三类模式命中**均为 0**：

| 模式 | 命中 |
|---|---|
| `gho_[A-Za-z0-9]{20,}` | 0 |
| `Bearer [A-Za-z0-9._-]{40,}` | 0 |
| `sk-[A-Za-z0-9]{16,}` | 0 |

⇒ 仓库里本来就没有真 token / API key。命中的 email 与 GUID 全是测试占位。
这条要写下来，避免后来者以为「私有化 = 更安全」而据此做更多假设。

## Alternatives considered

- **不转 private** — 它最强的理由是**保住自动更新通道**：这是唯一让存量用户
  无感升级的机制，也是 D15 里「Release 是对外版本唯一信号」那条的前提；
  转私有等于主动放弃这条通道。否掉的原因是这是**业主的指令，不是技术选项** ——
  决策笔记可以记录代价，但不能把业主已定的口径改写成技术权衡。

- **在客户端里内置凭据去拉私有 Release** — 它最强的理由是**两全**：仓库保持私有，
  自动更新也照常工作，不必在「安全」与「可升级」之间二选一。否掉的原因是
  那把凭据要**发到每个用户手里**（客户端里的一切都可被提取），
  等于把私有仓库的读权限公开，泄露面远大于收益 —— 而且它一旦泄露，
  收回成本是所有已发布客户端。

## Consequences

- **收益**：符合业主对仓库可见性的要求。
- **代价**：**应用内自动更新对所有已安装客户端失效**，包括业主自己的。
  恢复通道只有两条，二选一：
  1. **仓库改回 public**
  2. **把 `endpoints` 换成别的公开托管点**（自建静态站 / 对象存储 / 另一个公开仓库）
- **⚠ 关键限制**：只改 `endpoints` 而**不改客户端**对已安装用户无效 ——
  端点写死在已发布的客户端里。要让存量用户恢复，只能走**手动下载覆盖安装**。
- **代价与已知上限**：`releases/latest` 的语义因此变得不可依赖 ——
  它仍会指向某个 Release，但客户端拿不到。**信号**：若业主问「为什么检查更新没反应」，
  先确认仓库可见性，而不是去查 updater 配置。
- **代价**：这条决定的代价是**当初就写明的**。若某天「自动更新」比「仓库私有」
  更重要，那是**业主的取舍**，不是技术判断 —— 不要因为「实现起来麻烦」就自行翻案。

## Verification

- 端点定义：`src-tauri/tauri.conf.json` 的 `plugins.updater.endpoints` 第一项。
- 失效判据（可复现）：匿名访问 `releases/latest/download/latest.json` 返回 **404**。
- 恢复判据：同一 URL 匿名访问返回 **302**（本仓库 public 时期实测）。
