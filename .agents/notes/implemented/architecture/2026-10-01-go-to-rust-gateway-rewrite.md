# Agent Note: 网关从 Go 全量重写为 Rust，走「多产品等价」路线

Status: implemented

## Problem

原 `docs/DECISIONS.md` D01（从 DECISIONS.md 迁移）。网关内核原本是 Go 实现（`go-gateway/`）。
1.0.13 时上游 `momo0410/ai-gateway` 的 PR#2 已经把 Go 网关删掉、换成 Rust，并且**不接 Qoder**
（ZCode 只作为「可导入的客户端」）。当时本仓库**选择不跟**，只做定点摘取（见 1.0.13 的发布说明
第一节「保留未并的部分（有意）」）。2026-10-01 业主改口径为「我们也换成 rust 全重写」，
1.0.14 落地。

这条决定要回答的是：**换成 Rust 时，既有产品能力怎么处理**。若照抄上游 PR#2 的形态，
Qoder / ZCode / Trae 的能力会被裁掉一大截；若保留 Go 主线不动，则会长期停在一条与上游分叉的
实现上。两个方向的代价都不小，必须在动手前定下来。

## Decision

### 产物与代码位置

网关内核是 `crates/ai-gateway-router`（Rust），产物 `target/<profile>/gateway.exe`。
Go 侧不再产出可构建的网关（`go-gateway/` 的处置见
[Go 参照实现留在仓库但退出构建链](2026-10-01-go-gateway-retained-out-of-build.md)）。

### 「多产品等价」：逐项保留，不做功能裁剪

重写按「**多产品等价**」进行：Qoder / ZCode / Trae 的能力在 Rust 侧**逐项保留**，
不做功能裁剪。即 Rust 版是 Go 版的等价替换，不是「先做最小可用、以后补齐」。

### ★ 代价（重写真实付过的学费）

Rust 版搬了**实现**、丢了**接线** —— Go `main.go` 的启动期接线（CLI 子命令拦截、
三个后台循环）全在 **HTTP 面之外**，所以 43 项 HTTP 验收**一条都抓不到**。
症状是「Qoder 定时领取不触发」「ZCode 自动领取完全不跑」「CLI 子命令让界面卡死」。
可复用的排查方法记在 1.0.14 的发布说明第二节：**把 Go `main.go` 的启动接线清单与
Rust `bin/gateway.rs` 逐条对差**。

这不是「重写质量差」的泛泛结论，而是一条可复用的判据：**验收覆盖面由接口面决定，
HTTP 验收天然看不到进程启动期做的事**。重写类改动必须单独对一遍启动接线。

## Alternatives considered

- **整体跟随上游 PR#2 的路线**（删 Go 网关、不接 Qoder、ZCode 降级为可导入客户端）——
  它最强的理由是**与上游同构**：少维护一份分叉、后续跟随上游更新的成本最低，也不必
  自己为 Qoder 的协议细节负责。否掉的原因是那会丢掉 8,448 行 Qoder 与 15,803 行 ZCode
  的既有能力，是**功能倒退**，不是迁移。

- **保留 Go/Rust 双实现并行** —— 它最强的理由是**风险最低**：可以先按模块逐个迁，
  任何一块出问题都能留在 Go 侧继续跑，且随时可回退到已验证的旧实现。否掉的原因是
  两套流式栈、两套超时语义，长期成本高于一次性重写。

## Consequences

- **收益**：网关只有一个实现、一套流式栈与一套超时语义，能力面与 Go 版等价
  （Qoder / ZCode / Trae 逐项保留）。重写完成后构建链上已无 Go 依赖，Go 只作为
  仓库内的参照实现存在。
- **代价与已知上限**：一次性重写的学费是「实现搬过来了、接线没搬」这类缺陷 ——
  它们在 HTTP 面之外，43 项 HTTP 验收抓不到，只能靠人工对差启动接线清单发现。
  **什么信号发生时必须重访该决定**：不翻案。重写已完成、构建链已无 Go 依赖；
  除非出现 Rust 侧无法解决的硬阻塞（例如某上游 SDK 只有 Go 实现），否则不回到 Go 主线。

## Verification

- 规模证据（原文口径）：Qoder 8,448 行、ZCode 15,803 行；43 项 HTTP 验收。
- 覆盖缺口可复现：43 项 HTTP 验收对「CLI 子命令拦截 / 三个后台循环」这类启动期接线
  零覆盖，症状为「Qoder 定时领取不触发」「ZCode 自动领取完全不跑」「CLI 子命令让界面卡死」。
- 排查口径：`1.0.14` 的发布说明第二节 —— 把 Go `main.go` 的启动接线清单与 Rust
  `bin/gateway.rs` 逐条对差。
