# Agent Note: 桌面应用与网关同进程树，网关 gzip 内嵌进主程序

Status: implemented

## Problem

原 `docs/DECISIONS.md` D03（从 DECISIONS.md 迁移）。原条目只标「1.0.0 起」，具体日期未证，
此处按 1.0.0 更名日（2026-09-16）取锚点。

需求是「一个安装包、一个界面、一个进程树」：用户不该被迫管两个可执行文件。若网关作为
独立文件随包分发，用户要管两个文件、版本易错配；若运行时下载网关，则离线不可用、
且引入新的失败面。

这条决定还附带解决了一个真实缺陷类：**「新功能在开发机上好好的，装完却没有」**。
根因是 `build.rs` 会无条件内嵌 `embedded/gateway.exe` 里当时躺着的那一份，而
`build-signed.ps1` 一度从不构建网关 —— 构建日志没有任何异常，装出来的包里却是旧网关。

## Decision

### 用户只拿到一个可执行文件

用户只拿到**一个** `ai-gateway.exe`。

### 构建期：gzip 压缩 → `OUT_DIR` → `include_bytes!`

构建期 `build.rs` 把网关二进制 gzip 压缩后放进 `OUT_DIR`，`gateway_embed.rs` 用
`include_bytes!` 编进主程序。

### 运行期：首次启动解压到指纹文件名

运行时首次启动解压到 `%USERPROFILE%\.wb-switch\gateway\bin\gateway-<指纹>.exe`。

### 进程树：网关是子进程，被宿主 Job Object 托管

**网关是主程序的子进程，且被宿主 Job Object（`KILL_ON_JOB_CLOSE`）托管** ——
主程序死，网关被系统连带回收，不留孤儿。

### 构建期强制重建 + SHA256 双端比对

现在的约定是 `build-signed.ps1` 的 `[3/4]` 步**强制重建**网关，并做构建前后
SHA256 指纹比对。

### 为什么落地文件名带指纹

指纹 = 「内嵌数据长度 + 内容哈希」。升级后指纹变化 ⇒ 落到**新文件**，不会复用旧版本网关；
同时避免反复覆盖同一文件导致杀软反复扫描。

它还是「正在跑的网关是不是本构建释放的」的**唯一判据** —— 正在跑的进程读不出自己内嵌的
指纹，但**文件名**里带着它（升级后自动换掉旧网关靠的就是这条）。

### ★ 已知取舍（不修）：写错一位的 FNV-1a 质数

`fingerprint()` 里的 FNV-1a 质数写成了 `0x1000_0000_01b3`（标准值是 `0x100000001b3`，
多一个 0）。**不修** —— 指纹只用于缓存文件名与 `cleanup_old()` 的保留判定，仍然稳定且对
内容敏感；改质数会让所有用户的落地文件名变化、触发一次无谓重写。

⚠ 写断言脚本时要**照源码口径复算**（长度段是 **gzip 载荷**长度，不是解压后的 exe 长度）。

## Alternatives considered

- **把网关作为独立文件随包分发** —— 它最强的理由是**结构最简单**：主程序不必内嵌、
  不必解压、不必管指纹与清理，网关也能独立升级与单独替换。否掉的原因是用户要管两个文件、
  版本易错配。

- **运行时下载网关** —— 它最强的理由是**主程序体积最小**，且网关可以脱离应用发版节奏
  独立更新、按需下载。否掉的原因是离线不可用、且引入新的失败面。

## Consequences

- **收益**：用户视角只有「一个安装包、一个界面、一个进程树」；主程序死时网关被 Job Object
  连带回收，不留孤儿；指纹文件名让升级自动换掉旧网关，也是「跑的是不是本构建释放的那份」
  的唯一判据；`build-signed.ps1` 的 `[3/4]` 强制重建 + SHA256 双端比对堵住了
  「内嵌旧网关」这个真实缺陷类。
- **代价与已知上限**：`fingerprint()` 里的 FNV-1a 质数是错的（`0x1000_0000_01b3`），
  **有意不修** —— 它只影响缓存文件名与 `cleanup_old()` 的保留判定，仍稳定且对内容敏感，
  改了会让所有用户的落地文件名变化、触发一次无谓重写。断言脚本必须照源码口径复算
  （长度段是 **gzip 载荷**长度，不是解压后的 exe 长度）。**什么信号发生时必须重访该决定**：
  出现「同一台机器要同时跑多个不同版本网关」的需求时 —— 那时需要显式实例隔离，
  而不是靠指纹文件名。

## Verification

- 构建期闸门可复核：`build-signed.ps1` 的 `[3/4]` 步调用 `scripts/build-gateway.ps1 -Force`
  强制重建网关，并做构建前后 SHA256 指纹比对。
- 解包自检（无需安装）：内嵌网关是主程序 exe 内的一个 **gzip 流**；扫描 gzip 魔数
  `1F 8B 08` → 解压 → 应以 `4D 5A`（MZ）开头且 **> 1MB** → 与
  `crates/ai-gateway-core/embedded/gateway.exe.sha256` 比对。
- 指纹口径：长度段是 **gzip 载荷**长度（不是解压后的 exe 长度），质数为
  `0x1000_0000_01b3`（标准值 `0x100000001b3`，多一个 0）。
