# Agent Note: 账号库是唯一真源，网关凭证是派生素材

Status: implemented

## Problem

原 `docs/DECISIONS.md` D05（从 DECISIONS.md 迁移）。

宿主 GUI 与网关是**两个独立进程**，各自需要读写凭证。天然的做法是让两份数据「保持一致」，
但两个存储的**格式根本不同**：

- 时间戳单位：账号库用**毫秒**，网关凭证用**秒**
- 字段集：账号库含 `profile_raw`、`auth_raw` 等客户端字段，网关不需要也读不懂

若不把「谁是真源、谁是派生」定死，两边会各自写入、互相覆盖，出现「在 A 里删了账号、
B 里还在用」或「B 刷新了 token、A 下次启动又写回旧的」。这类冲突不会报错，
只会让用户看到「明明删掉的账号还在消耗额度」。

## Decision

`%USERPROFILE%\.wb-switch\accounts.json` 是**唯一真源**；
`%USERPROFILE%\.wb-switch\gateway\gateway_auths\` 是**派生素材**，删掉可自动重建。

两个存储不合并 —— 格式差异见上，合并要么让网关跟着宿主的内部数据结构演进，
要么让宿主迁就网关的秒级时间戳。改成「一份真源 + 一份派生」后方向单一：
宿主写账号库，网关读派生目录。

### 同步规则（有意不对称）

| 方向 | 规则 |
|---|---|
| 账号库 → 网关 | 按 uid 生成嵌套形凭证；账号删除或模式切换后自动清理残留 |
| 网关 → 账号库 | 网关自身刷新 Token 后，按**过期时间较新者**回写；**空 refresh token 不覆盖已有值** |
| 无变化 | 不写盘 —— 避免无意义的文件时间戳变动与网关重启 |

「较新者胜」而不是「网关胜」：网关刷新的 token 通常更晚，但也可能因为时钟或重试
写回一个更旧的；按时间比较能让两个方向都收敛。
「空 refresh token 不覆盖」是必须的例外 —— 上游偶尔在刷新响应里不给 refresh token，
照抄回去会让账号**永久失去刷新能力**，且用户无从察觉。

## Alternatives considered

- **让网关直接读 `accounts.json`** — 它最强的理由是**省掉一整层**：不需要派生目录、
  不需要同步逻辑、也就不存在「两份数据不一致」这个缺陷类，宿主改了账号库网关立刻看到。
  否掉的原因是它把**两个进程的耦合面**从「一个文件格式」放大到「宿主内部数据结构」：
  网关要跟着宿主的字段演进走，宿主一改字段网关就崩；且网关需要的秒级时间戳与嵌套形状
  仍要现场换算，换算逻辑还是得写 —— 等于把同步器换成适配器，没有真的省掉。

- **继续用 `.ai-gateway` 并靠「双向同步」维持两版一致** — 它最强的理由是保住 1.0.0
  的既有布局，老用户不需要迁移。否掉的原因是那需要写一个**永不收敛**的同步器：
  两版同时装在一台机器上时，谁都没有权威地位，任何冲突都要靠时间戳猜。

## Consequences

- **收益**：真源唯一，冲突有明确的裁决规则（较新者胜 + 空值不覆盖），
  不需要用户理解「哪个文件说了算」。
- **收益**：派生目录可以随时删除重建，排障时「删掉 `gateway_auths` 重启」是安全操作。
- **代价与已知上限**：多了一层同步代码与一个「派生目录可能过期」的窗口 ——
  `multi_product_credit_patrol` 那类巡检刷新账号库后需要显式触发重新同步，
  否则网关侧看到的是旧凭证（本仓库为此有 `gateway::resync_native_config()`，
  且已接在账号刷新与巡检的路径上）。
  **信号**：若出现「账号库已更新但网关仍在用旧凭证」，且不是漏调 resync 造成的，
  就说明这份不对称规则需要重审。
- **代价**：派生目录里的凭证是明文落盘的，与账号库同级敏感 ——
  这也是它必须留在 `%USERPROFILE%` 下、且不能被任何文档或测试带进仓库的原因。

## Verification

- 账号库路径：`crates/ai-gateway-core/src/modules/config.rs` 认
  `AI_GATEWAY_HOME` 环境变量，未设时用 `%USERPROFILE%\.wb-switch`。
- 派生方向：`gateway::resync_native_config()` 只写文件、不重启网关；
  调用点包括 `qoder_login::refresh_account` / `zcode_login::refresh_account` /
  `multi_product_credit_patrol::run_once`。
- 删派生目录可重建：删掉 `gateway_auths\` 后重启网关，凭证按账号库重新生成。
